# 模型 錯誤

趨勢

每一點代表一輪評測。觀察延遲與穩定度是否隨時間波動，而不只看平均值。

P95 延遲（對數刻度）

方法與資料來源

所有題目與數據皆可追溯至原始來源。

題庫

27 題，全部有出處，沒有自行編造的題目。正確率只計算有標準答案的分類與抽取題。

  • Banking77：真實銀行客服提問的意圖分類（CC BY 4.0）
  • Financial PhraseBank：財經新聞情緒判斷（CC BY-NC-SA 3.0）
  • 金管會與中央銀行新聞稿：抽取、摘要、說明（公文）

成本

OpenRouter 公開的每 token 價格 × 中央銀行新台幣對美元收盤匯率，於每一輪評測當下記錄，之後價格變動不會改寫歷史。實際呼叫使用免費額度，此數字代表同樣流量在付費 API 上的市場參考價。

延遲與穩定度

從台灣（GCP asia-east1）發出請求到收到完整回應的時間，包含跨國網路。P95 表示 95% 的請求比這個值快。評測不自動重試，失敗如實記錄。

架構

Cloud Scheduler 每 6 小時觸發 Cloud Run Job 執行評測，結果存入 Firestore；本頁與查詢 API 由 Cloud Run 服務提供。全部資源以 Terraform 建立。

05

方法與資料來源

題庫

27 題，全部有出處：Banking77（銀行客服意圖）、Financial PhraseBank（財經情緒）、金管會與中央銀行新聞稿（抽取、摘要、說明）。正確率只計算有標準答案的分類與抽取題。

成本

OpenRouter 公開的每 token 價格 × 中央銀行新台幣對美元收盤匯率，於每一輪評測當下記錄。實際呼叫使用免費額度，此數字代表同樣流量在付費 API 上的市場參考價。

延遲

從台灣（GCP asia-east1）發出請求到收到完整回應的時間，包含跨國網路。P95 表示 95% 的請求比這個值快。

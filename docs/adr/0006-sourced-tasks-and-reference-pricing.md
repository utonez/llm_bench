# 0006 · 題庫必須有出處；成本採市場參考價

## 題庫

**背景**：最初的題目是 AI 輔助撰寫的模擬情境，無法查證，也可能有爭議。

**決定**：
- 題目只取自可查證的公開來源：Banking77（CC BY 4.0）、Financial PhraseBank（CC BY-NC-SA 3.0）、金管會與中央銀行新聞稿（公文，依著作權法第 9 條不受保護）
- 每題都必須有 `source` 欄位（網址、授權、在原始資料中的位置），**沒有出處的題目無法載入**
- 建立時以腳本比對每題引文與下載的原始檔，27 題全部逐字相符
- 只自動評分有標準答案的題目（分類、抽取）；摘要和說明題只量測延遲與成本

## 成本

**背景**：實際呼叫使用免費額度，成本為 0，但選型需要知道正式上線的成本。

**決定**：
- 價格：OpenRouter 公開的每 token 價格，作為**市場參考價**
- 匯率：**中央銀行**的新台幣對美元銀行間收盤匯率（data.gov.tw 資料集 7232 的官方 API）
- **每一輪抓一次**，成本依當下價格記錄，之後價格變動不會改寫歷史
- 任一來源掛掉時，這一輪仍會完成，只是成本欄位留空

**考慮過的替代方案**：臺灣銀行牌告匯率 CSV。它對程式存取回傳機器人驗證頁面，因此**不嘗試繞過**，改用央行的官方開放資料。

**影響**：
- ✅ 題目與數據都可以追溯、驗證
- ⚠️ 題庫只有 27 題，正確率的參考價值有限；平台的重點是延遲、穩定度與成本
- ⚠️ 參考價可能和直接向原廠購買的價格不同
